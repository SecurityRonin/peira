# Naming — competitive analysis and shortlist

**Date:** 2026-08-09
**Status:** **DECIDED — `peira`.** Renamed 2026-08-09. This document is kept as the
record of why, including the recommendation that was not taken.
**Method caveat:** availability figures are live API responses (Tier 1). The
competitive landscape is **single-source** — see *Method and caveats*.

---

## Executive summary

**Rename.** `elenchus-cli` 0.15.1 is taken on crates.io by
[m62624/elenchus](https://github.com/m62624/elenchus), described as *"Command-line
interface for the elenchus consistency checker: check a .vrf string or file and
report CONSISTENT / WARNING / UNDERDETERMINED / CONFLICT."* Last updated
2026-07-17, 397 downloads.

That is not a squat, and it is not merely a name clash. It is an actively
maintained tool that **checks consistency and emits verdict states** — the same
conceptual territory this project occupies. Publishing `elenchus-core` and
`elenchus-lens` beside it would confuse users of both. ADR-0009 requires names to
be settled before publishing, because crates.io allows deletion only within 72
hours.

**Recommended: `anakrisis`.** Second choice `peira`. Both are free on crates.io,
free as a repo name in the SecurityRonin org, and carry no software collision I
could find.

> **Decision (2026-08-09): `peira`.** The owner chose the second-ranked option.
> Recorded rather than quietly amended, because a naming doc that retrofits its
> recommendation to the decision is worthless the next time one is needed.
>
> What the choice accepts: the pronunciation ambiguity noted below (PAY-ra /
> PEE-ra / PIE-ra to an English reader), and the two UK consulting firms trading
> as PEIRA — different field, so weak likelihood of confusion, but genuine
> commercial use.
>
> What it gains: five letters instead of nine; no *crisis* overtone; and πεῖρα is
> the root behind *empirical*, *experiment*, *experience* and *expert* — all from
> PIE \*per-, "to try, to risk". For a tool whose users are expert witnesses,
> being named after the word that produced "expert" is a better line than
> `anakrisis` could offer.

## The common core

The cross-cutting value proposition, the one that survives across every user —
expert witness, forensic examiner, academic researcher, lawyer:

> **A claim may not be relied on until it has survived examination — and the
> system, not its author, decides whether it has.**

Everything distinctive follows from that sentence: the gates, the absent `status`
field, the generated safe statement, the refusal to freeze a packet over an
unexamined claim.

## Category analysis

There is **no established category** to claim. The adjacent ones are each a poor
fit:

| Adjacent category | Who is there | Why it does not fit |
|---|---|---|
| Argument mapping | [Kialo](https://en.wikipedia.org/wiki/Kialo), [Rationale](https://rationaleonline.com/), [Argdown](https://argdown.org/) | Education and debate. Maps arguments; enforces nothing. Argdown is closest in *form* — "Markdown for argument mapping" — but has no gates and no evidence grading. |
| Evidence/claim provenance | [nanopublications](https://nanopub.net/), micropublications, [Evidence Graphs (EVI)](https://link.springer.com/chapter/10.1007/978-3-030-80960-7_3) | Academic, RDF/semantic-web, publication-oriented. EVI does extend PROV with defeasible reasoning — genuinely close on theory — but it is a data model and a research programme, not a practitioner tool with a CLI. |
| PKM | Obsidian, Logseq, Roam, Tana | Storage and linking. No epistemics at all. |
| Legal/forensic e-discovery | Relativity, Everlaw, Harvey | Document review and drafting. Claim-level provenance is absent. |
| Fact-checking | ClaimBuster, Full Fact | Verdicts on public claims, not a working discipline for your own. |

**The whitespace:** local-first, markdown-native, *deterministically enforced*
examination gates with a court-ready export. Nobody occupies it.

## Naming implications

**Commoditised — avoid:** argument, claim, evidence, graph, map, logic, reason,
think, verify, proof, fact, check, truth, AI, chat, sense.

Note the irony trap: this product's own lint bans the word "proves", so any name
built on *proof* would undercut it.

**Ownable:** the vocabulary of *the examination a thing must pass before it may be
relied on* — assay, scrutiny, vetting, touchstone, preliminary hearing.

## Shortlist

All verified 2026-08-09 against the crates.io API and the GitHub API.

| Name | Meaning | crates.io | SecurityRonin repo | Notes |
|---|---|---|---|---|
| **anakrisis** ἀνάκρισις | The Athenian **preliminary examination**: a magistrate examined the claim, parties and evidence and decided whether the case could be heard at all | free | free | Names exactly what the tool does. No software collision found. 9 letters. |
| **peira** πεῖρα | Trial, attempt, the test of experience — root of *empirical* and *experiment* | free | free | Short and clean, but says less. Two UK consulting firms trade as PEIRA (different field). |
| **dokimasia** δοκιμασία | The Athenian scrutiny an official passed **before taking office** | free | free | Excellent meaning, awkward to spell and say. |
| **pariksha** परीक्षा | Sanskrit: examination, test | free | free | Ties to the Nyāya lens — but see the objection below. |
| **mingjing** 明鏡 | The bright mirror that shows things as they are | free | org handle taken (repo name free) | Fits murdock's CJKV-first positioning. Opaque to non-CJK readers. |

**A real objection to the Sanskrit and Chinese options:** the catalogue deliberately
draws on **five or more traditions**, and a meta-test enforces that. Naming the whole
suite from one lineage privileges it over the others, which cuts against the design
principle that keeps "universal" universal. The Greek options are less exposed to
this only because `anakrisis` and `dokimasia` name a *civic-legal procedure* rather
than a school of thought — and the courtroom is where this product actually lives.

| Name | Why not |
|---|---|

| `basanos` | The touchstone for testing gold — but in Athenian law it also meant *testimony extracted under torture*. Fatal connotation. |

## Trademark and usage signals

**Not legal clearance.**

- **anakrisis** — no software product, company or mark surfaced. Appears only as
  the Greek legal-historical term. Lowest apparent risk.
- **peira** — [PEIRA LTD](https://find-and-update.company-information.service.gov.uk/company/15532835)
  and [PEIRA CONSULTING LIMITED](https://find-and-update.company-information.service.gov.uk/company/12429043)
  are UK companies in telecoms/digital consulting. Different goods and services,
  different buyers, so likelihood of confusion with a Rust developer tool is weak
  — but the name is genuinely in commercial use.

**Verdict:** `anakrisis` **go**; `peira` **yellow**.

**Domains are not a constraint here.** Fleet documentation is published at
`securityronin.github.io/<repo>`, so no domain purchase is required. For the
record, `anakrisis.com`, `peira.com` and `dokimasia.com` are all registered
(RDAP 200); `pariksha.com` could not be checked — the request failed with a
connection error, which is *unknown*, not *available*.

## If `anakrisis` is chosen

```
anakrisis/            repo (umbrella, not a crate)
  anakrisis-core      node/edge model, vault parser, grounded extension
  anakrisis-lens      the lens catalogue and its gates
  anakrisis-court     Court Mode packets
  anakrisis-index     derived SQLite index
  anakrisis-cli       binary: `anakrisis`
```

Reads correctly under ADR-0009: a self-describing prefix, role-suffixed members,
and the repo name is an umbrella rather than a crate.

## Method and caveats

- **Availability data is Tier 1** — live crates.io and GitHub API responses and
  RDAP lookups, dated 2026-08-09, re-runnable from the commands in this repo's
  history.
- **The competitive landscape is single-source and therefore weaker than the
  method requires.** The `competitive-naming` skill mandates triangulation across
  three or more independent models. Both external models were unavailable:
  **Codex returned HTTP 401** (not authenticated) and **agy required an
  interactive Google OAuth login**. Codex's own rollout transcript was checked and
  contained **zero assistant messages**, so it genuinely produced nothing rather
  than losing output in transit. The landscape above is therefore my own analysis
  plus web search — useful, but not the corroborated common core the method calls
  for. Treat the *category* and *whitespace* claims as provisional.
- To complete the method: authenticate both (`codex login`; `agy` and follow the
  OAuth URL), re-run the brief at
  `docs/strategy/brief.md`, and merge per Phase 2 before finalising.
- **Nothing has been renamed.** The repo remains local with its history intact.
