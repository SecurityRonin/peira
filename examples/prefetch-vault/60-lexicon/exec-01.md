title: execution
as_used: a program's code was run by the operating system on this machine
not_essence: >-
  a record that a program could run, or was staged or copied to run, is not the program
  having run; the presence of an executable is not its execution
stipulated: >-
  the Windows image loader created a process from the named image and began running its code
---

Bounded here to the loader creating a process. Nothing about who started it, or whether it
finished.
