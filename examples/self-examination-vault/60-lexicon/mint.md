title: mint
as_used: peira's own generated text asserts an evidentiary value — a grade, an attribution, or a score
not_essence: >-
  echoing the caller's own words back (the verbatim proposition, a tampered packet line) is
  not minting; the value must originate in peira, not in the input
stipulated: >-
  a response field whose value peira computed and that asserts evidence or a grading
