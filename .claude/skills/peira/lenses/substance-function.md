# Substance and Function 體用

<!-- Generated from peira_lens::CATALOG by cli/examples/gen_site.rs. Edit the lens in lens/src/lib.rs and regenerate. -->

**peira code:** `SUBSTANCE-FUNCTION` · **Chinese — 名家, 宋明理學, and the classics** · **Enforced** — owns a gate

**Failure mode:** reporting what a thing DID as though it established what a thing IS

**What it does:** a substance claim needs at least one substance-aspect support; function evidence alone cannot license it

**Enforced gates:** `PEIR-FUNCTION-AS-SUBSTANCE`

**Worked example:** "Amcache is an execution artifact" (substance) resting only on "Amcache recorded this path" (function). The record is a thing the artifact did; the claim is about what it is.
