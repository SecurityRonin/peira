# Analysis of Competing Hypotheses

<!-- Generated from peira_lens::CATALOG by cli/examples/gen_site.rs. Edit the lens in lens/src/lib.rs and regenerate. -->

**peira code:** `ACH` · **Modern — analytic and scientific method** · **Enforced** — owns a gate

**Failure mode:** confirmation by consistency — collecting evidence that fits the favoured hypothesis without asking what it rules out

**What it does:** an explanation above the association rung must name something it was tested against; diagnosticity is THREE-MARKS's half of the same rule

**Enforced gates:** `PEIR-RIVALS-UNENUMERATED`

**Worked example:** Evidence consistent with execution is usually also consistent with installation and with scanning, so it is not diagnostic and should carry no weight either way.
