# Double Crux

<!-- Generated from peira_lens::CATALOG by cli/examples/gen_site.rs. Edit the lens in lens/src/lib.rs and regenerate. -->

**peira code:** `DOUBLECRUX` · **Modern — analytic and scientific method** · **Catalogued** — a reading, owns no gate

**Failure mode:** disagreement that circles because the load-bearing belief was never located

**What it does:** find the belief whose reversal would reverse the conclusion, for both parties

**Worked example:** If neither side can name what would change their mind, the dispute is not yet about anything checkable.

**In the tradition:** Double Crux, developed at CFAR and set out on LessWrong (2016), is a method for a disagreement that circles: each side finds the belief that, if it flipped, would flip their conclusion too — the shared crux — and the argument moves there rather than everywhere at once. If neither side can name what would change its mind, the dispute is not yet about anything checkable. The lens keeps the demand: locate the load-bearing belief before arguing.
